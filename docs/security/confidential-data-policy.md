# 私密数据保护策略

## 仓库允许内容

- 源代码、测试代码、接口文档、部署脚本和 CI 配置。
- `.env.example` 中的占位变量。
- 明确标记为 demo 的演示数据。
- 脱敏后的测试样本。

## 仓库禁止内容

- `.env` 和任何真实密钥。
- GitHub token、云服务 token、数据库密码、证书私钥。
- 真实客户、联系人、合同、项目、财务、员工和绩效数据。
- 数据库备份、生产日志、服务器地址和内网地址。
- 未提交专利前的专利交底细节。

## 测试数据要求

所有 seed 数据必须使用演示名称、演示编号和假金额。真实生产数据进入测试环境前必须脱敏，脱敏范围至少覆盖姓名、电话、合同编号、银行账号、客户名称、金额区间和项目成果文件。

## 开发要求

- 开发人员只使用授权仓库提交代码。
- 核心分支开启代码审查。
- 核心金额修改、导出、规则变更和权限变更必须写入审计日志。
- 所有环境变量通过本地 `.env` 或部署平台注入，不写入源码。
