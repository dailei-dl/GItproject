# UI Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the DesignTwin web shell with a React enterprise admin layout, login placeholder, sidebar navigation, dashboard metrics, charts, risk list, and responsive behavior.

**Architecture:** The UI shell lives in `apps/web` and consumes shared package exports from `@designtwin/shared`. It does not call the backend yet; this branch establishes the visual structure and tested rendering contract for later API integration.

**Tech Stack:** React, TypeScript, Vite, Vitest, Testing Library, Ant Design, ECharts.
