# Org Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the DesignTwin API foundation with NestJS, JWT login, demo organization roles, data-scope permission checks, sensitive-field masking, audit logging, Prisma schema, and API documentation.

**Architecture:** `apps/api` owns the NestJS API. The module starts with deterministic demo users and in-memory services so auth, permissions, and audit behavior can be tested before wiring PostgreSQL. Prisma schema defines the persistent model that later branches will migrate into a running database.

**Tech Stack:** NestJS, TypeScript, Vitest, Supertest, JWT, Prisma.
