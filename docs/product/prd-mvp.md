# DesignTwin MVP PRD

## 目标

第一期 MVP 建立设计企业经营管理的核心数据闭环，让管理层和业务角色能基于同一套口径查看客户、合同、项目、资金、产值和风险。

## 主流程

```text
线索 -> 机会 -> 合同 -> 项目立项 -> 回款/支出 -> 产值分配 -> 经营看板
```

## P0 功能

- CRM：客户、联系人、线索、机会。
- 合同：合同、补充协议、合同转项目。
- 项目：项目档案、阶段、成员、任务、风险。
- 财务：收款计划、回款、开票、支出、外协成本。
- 产值：规则配置、项目产值池、部门分配、个人分配、调整审核。
- 看板：经营驾驶舱、分院总览、项目全景、产值分析。
- 安全：登录、角色权限、数据范围、敏感字段控制、审计日志。

## 暂缓功能

- 多租户计费。
- 行业模板市场。
- 复杂 AI 预测。
- 完整移动审批 App。
- 税务申报、总账核算、薪酬发放。

## 验收标准

- 用 demo 数据跑通完整主流程。
- 不同角色只能查看授权范围内的数据。
- 金额和产值计算不使用浮点数。
- 产值规则有版本、审批和审计记录。
- 本地部署可以通过 Docker Compose 启动。
