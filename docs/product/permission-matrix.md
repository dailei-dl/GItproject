# MVP 权限矩阵

## 角色

| 角色 | 数据范围 | 核心能力 |
| --- | --- | --- |
| 管理员 | 公司 | 用户、组织、角色、权限、系统配置 |
| 老板 | 公司 | 经营驾驶舱、全部项目和产值汇总、风险列表 |
| 分院负责人 | 分院 | 分院合同、项目、回款、支出、产值和人员排行 |
| 部门负责人 | 部门 | 部门项目、成员任务、部门产值、成员基础绩效 |
| 项目负责人 | 项目 | 项目档案、阶段、成员、任务、风险、项目产值链路 |
| 财务 | 授权公司或分院 | 回款、开票、支出、外协成本、财务口径复核 |
| 人事 | 授权公司或分院 | 员工档案、部门、岗位、人效基础指标 |
| 员工 | 本人 | 我的项目、我的任务、我的产值、个人中心 |

## 敏感字段

| 字段 | 默认可见角色 | 说明 |
| --- | --- | --- |
| 合同金额 | 管理员、老板、分院负责人、财务、授权项目负责人 | 员工默认不可见 |
| 成本金额 | 管理员、老板、分院负责人、财务 | 部门和项目角色按授权显示 |
| 净流水 | 管理员、老板、分院负责人、财务 | 默认不向普通员工展示 |
| 个人产值 | 管理员、老板、人事、本人、授权负责人 | 跨部门查看需授权 |
| 绩效评分 | 管理员、老板、人事、本人、授权负责人 | 支持脱敏展示 |

所有权限必须由后端强制执行，前端只负责菜单和展示控制。
